homelab-backup

homelab-backup is a private backup tool used by a single household. Each night it encrypts backups of the household's own home server and stores them in the household's own Google Drive account.

It is not a public service: nobody else can sign up or use it, and it only works with the owner's Google account.

It asks Google for the narrowest Drive permission available ("see, edit, create and delete only the specific Google Drive files you use with this app"). It cannot see any other files in the account.
